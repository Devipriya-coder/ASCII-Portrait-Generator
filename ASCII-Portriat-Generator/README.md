# ASCII Portrait Generator

A Python desktop application that transforms photographs into detailed ASCII art.

## Features
- Choose images from your laptop.
- Convert photographs into grayscale ASCII portraits.
- Display static portraits.
- Animated moving light-wave effect.
- Start and stop animation.
- Save ASCII artwork as TXT files.
- Centre-aligned portrait display.

## Technologies Used
- Python
- Tkinter
- Pillow (PIL)
- Math

## Installation

Install Pillow:

```bash
pip install pillow
```

## How to Run

Run the following command in the project terminal:

```bash
python advanced_ascii.py
```
